## Figma-MD V0.2.0 功能需求

### 1. 关于查看展示权限

1.1 当前小部件只能编辑者查看，目前的场景是直接将 Figma 原型给到研发查看，评估一下“可查看”角色如何能够打开小部件查看 md 内容。

### 2. UI视觉优化

2.1 md 格式显示，当前字号整体有点大，占空间，需要整体缩小 2 个字号。当前标题的字号巨大，需要找一个视觉比较平衡好看的 md 前端格式，保障 1、2、3 级标题字号不要大出正文太多。
2.2 当前 md 的行拖拽的操作 icon 被目录挡住了。需要优化显示。

2.3 当前目录折叠后还显示一小竖栏占用空间，需要折叠目录后不显示这个小竖栏，折叠 icon 可以放在标题栏或者悬浮在编辑页面。

2.4 “已保存”前面的“Markdown Block”——对应 icon不显示，去找这一行，将复制、下载按钮与标题放一行，按钮保持右对齐，“已保存”、“保存中”状态放在操作按钮左侧。

2.5 复制与下载按钮只有 icon 就行，不显示文字。

2.6 整个小组件名称（页面左上角）名称为“MD Block”。

### 3. Md功能优化。

3.1 md 的编辑器，点击/或者行移动 icon，是否能增加可视化的操作功能栏（比如一级标题、二级标题、序号、引用、代码、表格等等），方便不懂 md 格式的人可以插入对应格式。

3.2 md 编辑器点击行，显示未渲染的格式。可以参考Typora 的交互方式。举例：二级标题日常展示渲染后的结构，当光标移动到二级标题行，显示“## 二级标题”，可以直接修改，移出光标后保持md渲染。

3.3 需要能够插入图片附件并保存。下载查看是否打包成一个md文件还是md+图片素材文件夹文件包。

3.4 可以将画板插入到md文档中，以链接形式展示，链接名称为画板名称。链接为跳转到对应画板的链接，点击链接后figma画面跳转到对应的画板。

### 4. 操作优化

1. 去掉“预览”和“编辑”按钮，默认是有编辑权限就自动编辑，如果是查看权限只能查看。
2. 界面拖拽缩放，四个角或者四个边都可以进行页面缩放，四个右下角不需要显示折角的样式，鼠标到可缩放的位置边鼠标即可。
